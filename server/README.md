# Сервер «Четырёх Штолен»

Один файл `server.py` на Python 3.10+ без сторонних библиотек.

## Что делает сервер

- Передаёт сообщения между хостом и игроками, поэтому подключение не зависит от сети игрока.
- Создаёт аккаунты и хранит прогресс в облаке: монеты, уровень, задания, гардероб.
- Показывает рейтинг лучших игроков.
- Принимает жалобы на игроков.

Бой по-прежнему считает хост. Если хост выйдет, бой закончится. Голосовой чат идёт напрямую между игроками, а не через сервер.

## Запуск на своём компьютере

```bash
python server.py
```

Проверьте, что сервер работает: откройте <http://localhost:8787/health>.

## Переменные окружения

| Имя | Зачем | По умолчанию |
|---|---|---|
| `PORT` | Порт | `8787` |
| `DATA_DIR` | Папка базы. На хостинге это должен быть постоянный диск, иначе прогресс пропадёт при перезапуске | `./data` |
| `ADMIN_KEY` | Пароль для чтения жалоб | пусто: чтение жалоб выключено |

Жалобы можно прочитать по адресу `https://ваш-сервер/api/reports?key=ВАШ_ADMIN_KEY`.

## Размещение в интернете

Подойдёт любой хостинг, где можно запустить Docker-контейнер или Python и подключить постоянный диск: VPS, Fly.io, Railway, Render с платным диском. В папке лежит `Dockerfile`.

1. Разверните контейнер. Диск подключите в `/data`, придумайте длинный `ADMIN_KEY`.
2. Хостинг должен давать адрес с https: браузеры и Google Play требуют защищённое соединение.
3. В игре откройте «Настройки» → «Сервер игры», вставьте адрес вида `https://ваш-сервер` и нажмите «Сохранить».
4. Чтобы сервер был у всех игроков по умолчанию, впишите адрес в `DEFAULT_SERVER` в начале `index.html` и выпустите обновление.

## Ограничения

- Прогресс хранит и считает клиент. Сервер не даёт резко накрутить монеты и опыт, но полной защиты от читов нет: для неё бой нужно считать на сервере.
- База хранится в одном JSON-файле. Её хватит на тысячи игроков, но не на крупную нагрузку.
